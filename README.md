## 📌 পরিচিতি (About NJBP)

**নিরাপদ যাতায়াত বাস্তবায়ন পরিষদ (নিযাবাপ / NJBP)** হলো বাংলাদেশের সড়ক, আকাশ, রেলপথ ও নদীপথ—এই চারটি প্রধান ট্রানজিট সেক্টরের সমন্বয়ে গঠিত একটি নাগরিক পরিবহন সুরক্ষা ও নজরদারি প্ল্যাটফর্ম। সাধারণ যাত্রীদের সুরক্ষা, দুর্ঘটনা প্রতিরোধ, ঝুঁকিপূর্ণ ব্ল্যাকস্পট সংস্কার এবং জরুরি উদ্ধার ও ফার্স্ট এইড সচেতনতা বৃদ্ধির লক্ষ্যে এই সিস্টেমটি ডেভেলপ করা হয়েছে।

## 🌟 মূল বৈশিষ্ট্যসমূহ (Core Features)

### ১. ফ্রন্টএন্ড ও নাগরিক সেবা
- **ভিডিও হিরো ও গ্লসি স্ট্যাটাস কাউন্টার:** ব্যাকগ্রাউন্ড লেজি-লোডেড ভিডিওর ওপর ফ্রস্টেড গ্লাস ও সেমি-ট্রান্সপারেন্ট লাইভ স্ট্যাটাস কার্ড।
- **৪টি ট্রানজিট মনিটরিং বিভাগ:** 
  - 🚗 **সড়ক নিরাপত্তা (Road Safety):** ব্ল্যাকস্পট নিরীক্ষা ও স্পিড ম্যানেজমেন্ট।
  - ✈️ **আকাশপথ (Aviation Safety):** গ্রাউন্ড অপারেশন ও বিমান যাত্রীদের অধিকার।
  - 🚆 **রেলপথ (Railway Safety):** অরক্ষিত লেভেল ক্রসিং ও ট্র্যাক নজরদারি।
  - 🚢 **নৌপথ (Waterway Safety):** অতিরিক্ত যাত্রী প্রতিরোধ ও লাইফ জ্যাকেট নজরদারি।
- **জরুরি ক্র্যাশ উদ্ধার ও ফার্স্ট এইড গাইড:** দুর্ঘটনাস্থলে আহত ব্যক্তিদের মেরুদণ্ড সুরক্ষা (Spinal In-line Immobilization), ৩-৪ জনের সমান্তরাল লগ-রোল লিফটিং ও গোল্ডেন আওয়ার প্রোটোকল।
- **নাগরিক হ্যাজার্ড রিপোর্টিং (২৪/৭):** সাধারণ নাগরিকরা যাতায়াতের যেকোনো ঝুঁকিপূর্ণ ত্রুটি ছবি ও বিবরণ সহ সরাসরি রিপোর্ট করতে পারেন।
- **বহুভাষিক সমর্থন:** সম্পূর্ণ বাংলা ও ইংরেজি (BN / EN) এক ক্লিকে টগল সুবিধা।
- **১০০% মোবাইল রেসপন্সিভ:** স্মার্টফোন ব্যবহারকারীদের জন্য অপ্টিমাইজড টাচ-ফার্স্ট আর্কিটেকচার।

### ২. ব্যাকএন্ড ও অ্যাডমিন কন্ট্রোল প্যানেল (`/dashboard`)
- **মোবাইল-ফার্স্ট থাম্ব কন্ট্রোল:** স্মার্টফোন থেকেই অ্যাডমিন সম্পূর্ণ সাইট পরিচালনা করতে পারেন।
- **ইনসিডেন্ট ট্রায়াজ ও ম্যানেজমেন্ট:** লাইভ রিপোর্ট পর্যবেক্ষণ, স্ট্যাটাস পরিবর্তন (`তদন্ত চলছে`, `নিষ্পত্তি`, `বাতিল`) এবং রিপোর্টারকে সরাসরি কল করার ডায়াল বাটন।
- **ডায়নামিক সাইট সেটিংস:** কোনো কোড পরিবর্তন ছাড়াই হোমপেজের পরিসংখ্যান ও হটলাইন নম্বর পরিবর্তন।
- **টিম ও সাফল্য স্টোরি ম্যানেজমেন্ট:** কার্যনির্বাহী পরিষদ এবং বাস্তবায়িত উদ্ধার কার্যক্রমের গল্প পরিচালনা।

## 🛠️ টেকনোলজি স্ট্যাক (Tech Stack)

- **Backend:** PHP 8.2+, Laravel 11 (RESTful Architecture, Eloquent ORM)
- **Frontend:** React 18, Inertia.js, Vite
- **Styling:** Tailwind CSS, Lucide React Icons

## ⚙️ ইনস্টলেশন গাইড (Setup & Installation)

### পূর্বশর্ত (Prerequisites)
- PHP >= 8.2
- Composer
- Node.js >= 18.x & NPM
- MySQL Database

### ১. ক্লোন ও ডিপেন্ডেন্সি ইনস্টলেশন
```bash
git clone https://github.com/imtanvir70/njbp.git
cd njbp

# PHP ডিপেন্ডেন্সি ইনস্টল
composer install

# Node প্যাকেজ ইনস্টল
npm install
```

### ২. এনভায়রনমেন্ট কনফিগারেশন
```bash
cp .env.example .env
php artisan key:generate
```

`.env` ফাইলে ডেটাবেস ক্রেডেনশিয়াল যুক্ত করুন:
```env
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=njbp
DB_USERNAME=root
DB_PASSWORD=
```

### ৩. ডেটাবেস মাইগ্রেশন ও সিডিং
```bash
php artisan migrate --seed
```

> **ডিফল্ট অ্যাডমিন অ্যাক্সেস:**
> - **ইমেইল:** `admin@nirapodjatayat.org`
> - **পাসওয়ার্ড:** `password123`

### ৪. অ্যাপ্লিকেশন রান করা
```bash
# Frontend Build & Asset Watcher
npm run dev

# Laravel Local Server
php artisan serve
```
ব্রাউজারে ভিজিট করুন: `http://127.0.0.1:8000`
